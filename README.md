# terminal

Shell-sessioner för terminalfönstret i Jarri.

Fristående backend. Jarri kan använda den men den körs utan Jarri. Backend i `server.py`, bara standardbiblioteket, binder till `127.0.0.1`.

- Port: 8781
- Kör: `python3 server.py`
